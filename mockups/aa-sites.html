AA 관측지 시안

관측지를 프로필에 저장하고, 장비 연결 뒤에 확인·변경하는 흐름의 시안입니다. 기준 화면 1920×1080을 폭에 맞춰 줄여 보여 줍니다. 좌표·장소 이름은 예시이고, 카카오맵 자리는 그림으로 대신했습니다.

장비 연결 완료 → 막대 진행 (마우스를 올리면 멈춤)
   "현재 설정된 관측지는 위도 …° · 경도 …°입니다"  [관측지 변경]
   ├ 누르지 않음 ─────────────────────────────→ 출발 전 점검
   ├ 관측지 변경 → 관측지 고르기(목록 · 추가) → 저장 → 동기화 → 출발 전 점검
   └ 관측지 없음 → 관측지 고르기 (강제)
언제든: 상태 줄 관측지 연필 → 목록에서 고르기만 / 프로필 사진 → 프로필 변경 · 프로필 편집(관측지 목록 관리)

장비 연결 완료 · 관측지 있음

막대 위에 지금 관측지를 보여 주고, 문장 오른쪽에 "관측지 변경". 막대에 마우스를 올리면 멈추고 "잠시 멈춤"이 보입니다(그림은 멈춘 상태). 누르지 않으면 막대가 끝나고 출발 전 점검으로 갑니다.

장비 연결 완료 · 관측지 없음

관측지 고르기

"관측지 변경"을 누르거나 관측지가 없을 때 나오는 단계입니다. 프로필에 저장된 관측지(최대 10개)를 카드로 보여 주고, 지난번 관측지에 표시가 있습니다. 고르고 "저장하기"를 누르면 바로 N.I.N.A.에 반영하고 다음으로 갑니다. 목록이 비어 있으면 "관측지 추가"만 보입니다.

관측지 추가 (같은 단계 안에서)

"관측지 추가"를 누르면 카드 자리에 편집기가 펼쳐집니다(팝업 아님). 카카오맵에서 장소를 검색하거나 지도를 눌러 핀을 놓고, 카카오맵에서 복사한 좌표를 붙여 넣어도 됩니다. 고도는 좌표로 자동으로 채웁니다. "추가하기"를 누르면 프로필 목록에 저장되고 선택된 상태로 돌아갑니다.
