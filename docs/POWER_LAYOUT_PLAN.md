# 장비 전원 배선 — 의견과 구현할 것 (2026-10-09, 구현 전)

사용자 결정: 배선은 자주 바꾸지 않고, "어떤 장비냐"와 "전원을 어떻게 받느냐"는 다른 것이라 **프로필 생성·수정 화면**에서 정한다. 버튼을 누르면 프로필 오른쪽에 패널이 열리고 타입을 고른다.

## 버튼 이름 제안
- **"전원 배선"** (권장) — 짧고, 무엇을 정하는지 바로 보인다. 패널 제목은 "장비에 전원이 어떻게 들어가나요?"
- 다른 후보: "전원 연결 방식", "장비 전원 구조"

## 타입
| 타입 | 흐름 | 아이라가 다르게 하는 것 |
|---|---|---|
| **적도의 거쳐** (사용자 지금 배선) | 전원 → 적도의 → (새들 출력) → 파워박스 → 나머지 장비 | 파워박스 입력 0V = 적도의도 꺼짐 → 뒤 장비 모두 미룸, "적도의 전원을 켜면 파워박스도 켜집니다" |
| **파워박스 먼저** | 전원 → 파워박스 → 적도의 포함 모든 장비 | 파워박스 입력 0V면 모두 미룸. 적도의 포트가 없으면 적도의가 연결된 출력을 아이라가 켜고 기다림(카메라 전원과 같은 방식) — 그래서 **적도의가 어느 출력인지**도 고른다 |
| **따로따로** (제안 추가) | 적도의·파워박스가 각자 어댑터·배터리 | 파워박스 0V여도 적도의는 그대로 연결 시도. 파워박스가 없는 사람도 이 타입 |

의견: 두 타입이 대표적인 것은 맞다. 다만 아래가 빠지면 부족하다.
1. **따로따로 / 파워박스 없음** — 입문자에게 흔함. 이 타입이 기본값(아이라가 추측하지 않고 장비가 PC에 보이는지만 확인 — 지금 동작).
2. **장비별 예외: 카메라** — 같은 타입 안에서도 카메라는 배터리 또는 파워박스 출력(DC2 8V 등). 지금 `CameraPowerStore`(앱 전체 하나)를 프로필로 옮겨 이 패널에 둔다. 출력을 고를 때 전압 확인은 지금처럼.
3. **USB 경로** — 가이드 카메라·포커서가 파워박스 USB에 꽂혔나 PC에 바로인가. 파워박스 USB면 아이라가 USB 출력을 켜고(지금 `EnsureHubUsbOnAsync`), 안내 문구도 "파워박스 USB 출력"으로.

## 구현할 것
- **서버**: `Profile`에 `Power` (타입: Mount·Hub·Separate, 적도의 출력 이름(파워박스 먼저일 때), 카메라 전원(배터리|출력 이름), 가이드 카메라·포커서 USB 경로(Pc|Hub)). 기본 = Separate·배터리·Pc. `CameraPowerStore` 값을 지금 프로필로 옮기고(한 번) 없앰.
- `EquipmentConnector`가 프로필 배선을 읽어:
  - 파워박스 입력 0V(`HubInputVoltsAsync`) → Mount·Hub 타입만 뒤 장비 보류, Separate는 적도의 계속
  - 적도의 COM 포트 없음 + Hub 타입 → 적도의 출력 켜고 기다림(`SetHubOutputAsync`, 카메라 J05와 같은 길)
  - USB 경로가 Hub일 때만 `EnsureHubUsbOnAsync`·"파워박스 USB" 안내
  - 안내 문구를 타입에 맞게 (적도의 거쳐: "적도의 전원을 켜면 파워박스도 켜집니다")
- 마무리 장비 정리: 끄는 순서 안내를 타입에 맞게 (적도의 거쳐: 파워박스 출력 → 적도의 → 전원)
- **웹**: 프로필 생성·수정 화면에 "전원 배선" 버튼 → 오른쪽 패널: 타입 세 개(그림 카드 — 전원·적도의·파워박스 선 그림), 파워박스 먼저면 적도의 출력 고르기, 카메라 전원(배터리/출력 + 전압 확인), 가이드 카메라·포커서 USB(PC/파워박스). 장비 변경의 "카메라 전원" 줄은 패널로 옮기고 없앰. DESIGN.md에 규칙 추가
- 사용자 프로필(용인집)의 초기값: 적도의 거쳐 · 카메라 배터리(DC2 8V는 시험 때만) · 가이드 카메라·포커서 파워박스 USB
- 확인할 것(실기): Empire가 N.I.N.A.에 주는 입력 전압 칸 이름과 DC를 뺐을 때 값 — `HubInputVoltsAsync`는 이름이 안 맞으면 막지 않음

## 사용자 제안: 드래그로 전원선을 직접 잇기 (2026-10-09) — 의견
- 좋은 점: 타입에 갇히지 않아 어떤 배선이든 그대로 그릴 수 있고, 완성된 그림이 곧 배선도라 한눈에 보인다.
- 걸리는 점: ① 처음 쓰는 사람은 빈 화면에서 무엇을 이어야 할지 모름 ② 잘못된 연결 막기가 필요(순환, 전원 없는 장비, 전압 안 맞는 출력 — 카메라 7~8.4V를 12V 출력에) ③ 키보드·휴대폰(원격 접속)에서 드래그가 어려움 → 누르기만으로도 이을 수 있어야 함 ④ 만들 양이 타입 고르기의 몇 배.
- **권장: 둘을 합친다.** 패널 위에 타입 카드 3개(적도의 거쳐 · 파워박스 먼저 · 따로따로) → 고르면 배선도가 미리 그려짐 → 다른 점만 선을 끌어 고친다(예: 카메라 선을 배터리에서 DC2로). 드래그 대신 장비를 누르고 연결할 곳을 누르는 방식도 같이 둔다. 출력에 꽂을 때 전압 확인은 지금 카메라 전원과 같게.
- 순서: 1차 타입 카드 + 미리 그린 배선도(보기만) → 2차 선 끌어 고치기.

## 시안 검토 뒤 결정 (2026-10-09, mockups/aira-power-wiring.html) — 위 내용보다 우선
1. **장비 종류 사이의 전원 흐름만** 담는다. 실제 장비 이름·전압·출력 번호(DC1~6)·상시 여부는 담지 않는다. 상자에는 종류 이름만 (DC 전원 · 배터리 · 노트북 · 적도의 · 파워박스 · 카메라 · 포커서 · 이슬 방지 열선 · 가이드 카메라).
2. **타입(적도의 거쳐/파워박스 먼저/따로따로)은 없앤다** — 선 잇기만. USB 경로 칸도 없음. 전원 공급원은 DC 전원 · 배터리 · 노트북 셋, 나눠 주는 장비는 적도의 · 파워박스. 배선도는 크기·자리가 고정이라 선을 바꿔도 아무것도 커지거나 움직이지 않는다. 막는 것: 자기 자신, 서로에게서 받기(순환), 노트북 → 적도의·파워박스·열선. 전압 확인 없음.
3. **참고용·선택**: 비어 있어도 "전원이 없다"고 보지 않는다(빨간 표시·경고 없음). 실제 전원은 장비 연결 등 각 단계에서 확인한다.
4. **기본값 = 적도의 먼저**: DC 전원 → 적도의 → 파워박스 → 포커서·열선·가이드 카메라, 카메라는 배터리. "처음 배선으로"로 되돌림.
5. **실제와 다르면 아이라가 조용히 고친다** (알리지 않음, 백그라운드). 알 수 있는 경우:
   - 카메라가 PC에 없다가 아이라가 파워박스 출력을 켜자 나타남 → 카메라 = 파워박스
   - 적도의 포트(COM)가 없다가 파워박스 출력을 켜자 나타남 → 적도의 = 파워박스 (그 반대인 적도의 → 파워박스는 지울 것)
   - 파워박스 입력 0V인데 적도의는 연결됨 → 적도의는 파워박스 앞이 아님 (적도의 = DC 전원으로, 파워박스 = 모름 대신 그대로 두지 않고 DC 전원)
   - 파워박스 USB 출력을 끄면 가이드 카메라·포커서가 사라짐 → 그 장비 = 파워박스 (끄는 시험은 하지 않음 — 켤 때 나타나는 경우만 씀)
   - 알 수 없는 것은 바꾸지 않는다
- 위 "구현할 것"에서 바뀌는 점: `Profile.Power`는 장비 종류 → 공급원(dc·battery·laptop·mount·hub|null) 맵. 카메라 전원 출력 이름(`CameraPowerStore`, 전압 확인)은 장비 변경의 카메라 전원으로 그대로 두고, 배선도의 "카메라 = 파워박스"와는 따로(배선도는 참고용). `EquipmentConnector`의 동작을 배선도에 따라 바꾸는 부분(파워박스 0V일 때 적도의 계속 등)은 배선도가 참고용이므로 **실제 관측을 우선**하고, 배선도는 안내 문구에만 쓴다.

## 최종 규칙 (2026-10-10 사용자 확정) — 위의 모든 내용보다 우선
**배선은 아이라가 믿고 쓰는 값이다** (참고용 아님).
1. **처음 값**: 프로필에서 설정했으면 그 값, 안 했으면 기본값(적도의 먼저). 어느 쪽이든 아이라는 그대로 믿고 안내·판단한다.
2. **증거가 있으면 조용히 고치고, 그 뒤로는 고친 값을 믿는다** (알리지 않음). 사용자가 직접 설정한 값도 증거가 다르면 고친다(배선을 바꾸고 설정을 안 고친 경우가 대부분). 증거가 없으면 계속 그 값.
3. **나중에 추가한 장비**(장비 연결 단계에서 등록 — 예: 열선): 파워박스가 있으면 파워박스에서, 없으면 자체 전원. 실제 연결된 곳을 알아내면 그 값으로.
4. **배선도에 담는 것**: DC 전원이 적도의로 먼저 가는지 파워박스로 먼저 가는지(또는 둘 다 DC 전원에서 따로), 나머지 장비(카메라·포커서·열선·가이드 카메라)가 적도의(새들 포트)에서 받는지 파워박스에서 받는지. **배터리·노트북 상자 없음 — 선이 없으면 자체 전원**(카메라 배터리 등).
5. **잇기**: 상자 어디서든 다른 상자로 끌거나 차례로 누르면 이어진다. 방향은 상관없이 단(DC 전원 → 적도의·파워박스 → 나머지)으로 주는 쪽을 정한다. 적도의 ↔ 파워박스는 끈 쪽이 주는 쪽이고, 순서를 뒤집으면 앞이 되는 쪽이 DC 전원을 받는다(서로에게서 받지 않게). 막는 것: 나머지 장비끼리, DC 전원 → 나머지 장비 바로.
6. **배선을 믿으면 다르게 하는 일**:
   | 배선 | 파워박스 입력 0V | 적도의가 PC에 안 보임 |
   |---|---|---|
   | 적도의 → 파워박스 | 적도의도 꺼짐 → 다른 장비 미룸, "적도의 전원을 켜면 파워박스도 켜집니다" | "적도의 전원을 켜 주세요" |
   | 파워박스 → 적도의 | 모두 미룸, "파워박스 전원을 켜 주세요" | 파워박스 출력을 켜고 기다림(출력을 알 때만 — 아래) |
   | 따로 (둘 다 DC 전원) | 파워박스에서 받는 장비만 미루고 적도의는 계속 | "적도의 전원을 켜 주세요" |
7. **증거 예**: 적도의 → 파워박스인데 파워박스 0V에서 적도의가 연결됨 → 적도의는 DC 전원에서 따로. 파워박스 출력을 켜자 장비가 나타남 → 그 장비 = 파워박스(그리고 그 출력 이름을 기억). 파워박스 USB를 켜자 가이드 카메라·포커서가 나타남 → 파워박스. 알 수 없는 것은 바꾸지 않는다.
8. **출력 번호 제약**: 배선도는 출력 번호를 담지 않으므로 "적도의 = 파워박스"만으로는 어느 출력을 켤지 모른다. 장비 변경에서 출력을 골라 둔 장비(카메라 전원)와, 아이라가 출력을 켜서 나타난 것을 본 장비만 직접 켜고, 나머지는 "파워박스에서 ○○ 출력을 켜 주세요"로 안내.

## 구현 (2026-10-10)
위 "최종 규칙"대로 구현 — `Profiles/PowerWiring`·`PowerWiringStore`, `EquipmentConnector`(허브 뒤 장비만 보류, 보이면 연결하고 증거로 고침, 배선별 안내), 웹 `PowerWiringPanel`·`NewProfileScreen`. 출력 번호를 배우는 것(8번)은 아직 — 카메라 전원 출력만 직접 켬.
