## 1. 기준 화면 16:10 (사용자 결정)
- 현장에는 노트북만 가져감 → 노트북을 **배율 200%**로 쓰기로. 앱이 느끼는 크기 1920×1200 = 회사 모니터와 같음
- 기준 화면 1920×1080 → **1920×1200**. "16:10에서만 맞고 나머지는 깨지는" 게 아니라 "16:10에서 최적, 나머지는 통째로 확대·축소 + 여백"
- 바꾼 곳: `frame.ts` `FRAME_H`, `App.module.css` `.shell` 높이. 나머지는 이미 `cqw`·`cqh`라 따라옴
- 확인(헤드리스, 프로필 → 점검 → 장비 → 출발 전 점검 → 계획, 모두 스크롤 없음): 1920×1200·1536×960 여백 없음, 1920×1080 좌우 96px, 3440×1440 좌우 568px, 1280×800
- 계획 화면 그래프의 "달 ○○ 짐" 글자가 오른쪽 끝에서 잘리던 것(16:9에서도 있던 문제) → 자리가 없으면 막대 왼쪽에 "달 ○○ 뜸"

## 2. 계획 → 촬영 흐름 (Codex 요청서 IMPLEMENTATION_REQUEST_CODEX.md 검토 후 사용자 결정)
- 준비는 단계마다 Advanced API를 따로 부르고, N.I.N.A. 시퀀스는 본촬영·종료 동작에만
- 극축정렬은 앱을 다시 켜도 생략하지 않는다 (생략이 필요해지면 그때 논의). 이동 승인은 한 번(이동~센터링)
- 캘리브레이션: Claude 의견대로 — 그날 밤 극축정렬 뒤 한 번, 같은 밤 대상 변경엔 재사용
- 종료: "목표 장수·노출을 정상 확보 → 촬영 끝 → 뒷정리" 시나리오부터. 세부는 촬영을 만들며 정함
- SharpCap 설치 확인·다른 방법 입력 절차는 넣지 않는다 (V0.2쯤 검토). 지금 목표는 V0.1, 현재 V0.0.n
- 결과 표기는 "저장된 사진 n장" (화질 판정 전까지)
- 준비 ③ 대상 이동 때 대상이 아직 30° 아래면: 아직 보이지 않는다고 알리고 **멈춤** (자동 대기·강행 없음)
- 준비 ⑦ 시험 사진은 **항상 찍는다** (건너뛰기 없음)
- 가이딩 안정화: AA가 장비 스펙(주 카메라 픽셀당 각도)으로 **항상 규칙 판정**(충분 / 더 지켜보기 / 문제). 인터넷이 되면 앱의 AI가 같은 수치로 **설명을 덧붙임**(판정은 바꾸지 않음). **확정은 사용자가 "좋아요"로**
- 빌드 버전 표시: 부팅 화면·상태 줄(앱 이름 옆). n = 저장소 커밋 수 (두 PC·Codex가 같은 저장소라 어디서 빌드해도 같은 번호)
- 장비 없이 안 되는 것은 "연결·완료·성공"을 가정하고 진행. 가이드 카메라·가이드 망원경 실기는 다음 날 회사에서

## 3. 시퀀스 실험 (W1, 장비 없이)
- "N초 기다리기" 3개짜리 시퀀스를 JSON으로 넣고 시작 → 중지 → 다시 시작: **끝난 항목은 건너뛰고, 중단된 항목만 처음부터** 다시 실행
- 사용자가 실험용 N.I.N.A. 프로필 **AstroAssistant**(시뮬레이터 카메라)를 만듦. 시작 시 프로필 선택 옵션은 끔
- "2초 노출 × 5장"을 3장 저장 뒤 중지 → 다시 시작: **완료 장수 3/5 유지 → 5/5, 저장된 파일 정확히 5장** (중단된 노출 1장만 버리고 다시). → 복구는 "중지 → 해결 → 다시 시작"으로 충분, AA가 남은 장수로 시퀀스를 다시 만들 필요 없음
- 실험 뒤 되돌림: 빈 시퀀스, 카메라 연결 해제, 사진 저장 폴더 원래대로, 활성 프로필 "유성철"

## 3-1. W2 계획 확정 · W3 준비 화면 골격
- W2: 계획 칸에 실행 값(좌표·방향 유지·종료 규칙·끝난 뒤 동작). "이 계획으로 준비 시작" = 확정(`POST /api/plan/confirm`), 찍을 수 없으면 이유. 첫 인사 "오늘은 무엇을 촬영하실 계획인가요?"
- W3: 준비 화면 쉐브론 7칸, 서버 `PrepareRunner` + 모의 장비 `SimulatedPrepareDevices`. 헤드리스로 극축정렬 → 대상 낮음 멈춤 → 이동 → 초점 실패·다시 시도 → 가이딩 판정 → 시험 사진 → 촬영 시작까지 확인

## 4. 성도
- 이 노트북의 N.I.N.A. 구도 도우미 캐시(`%LOCALAPPDATA%\NINA\FramingAssistantCache`)에 전천 하늘 사진이 있음: 5°×5° 조각 2,131장, 각 2000px(약 9″/px), HiPS2FITS, 색인 `CacheInfo.xml`. 인터넷 없이 구도 미리보기에 쓸 수 있다 (읽기 전용)
- 사용자가 예전에 온라인에서 받아 둔 것. 지금은 그대로 쓰고, 성도가 없거나 바꾸는 경우는 흐름 완성 뒤 개편. **집 PC에는 없음** → 집에서는 성도와 관계없는 작업
