## 1. 오늘 앱에 들어간 것 (시안 → 코드)
- **NINA 요청 대기 시간 분리**: 조회 5초, 장비 연결 60초 (`NinaApiClient.QueryTimeout`/`ConnectTimeout`)
- **하단 단계 레일** `StepRail`: 연결 → 점검 → 계획 → 준비 → 촬영 → 마무리, 모든 화면 같은 자리·높이. 맨 오른쪽 **앱 끄기**(문 아이콘, 데스크톱 창에서만)
- **1단계 인터넷 연결 확인** (`InternetCheck`, 시작·계획은 온라인 필수)
- **출발 전 점검 화면**: 3×2 타일, 누르면 그림 카드가 뒤집히며 V, "모두 확인 완료"(예전 "건너뛰기"), 6개 되면 자동 진행
- **촬영 계획 화면 + AI 대화**
  - 왼쪽 대화(선택지 칩) · 오른쪽 위 "오늘 밤" 그래프 · 계획 4칸 · 계획 카드 → "이 계획으로 준비 시작" → 준비 자리(아직 화면 없음)
  - 숫자는 코드(C#): 어두운 시간·대상 고도·달·화각·예상 장수 (`Astro.Core/Sky`), AI는 도구로 받아 말만
  - 대상 목록 = **N.I.N.A. 데이터베이스**(NINA.sqlite, 약 1만 7천 개). 관측지·망원경·카메라 = N.I.N.A. 프로필. 구름 = Open-Meteo
  - **AI 회사 교체 가능 구조**: 공통 형식(`Astro.Core/Assistant`) + 회사별 번역기(`Providers/`). 지금은 Gemini
  - **연습 대화**(`Assistant:Provider=scripted`): AI 없이 같은 도구로 계획을 채움. 한도 초과·키 문제면 자동으로 넘어감
- **데스크톱 창**: 전체화면으로 시작(F11 창 모드, Alt+F4 끄기), 두 번 켜면 켜진 창을 앞으로

## 2. 장비 연결 화면 (사용자와 여러 번 다듬음)
- **장비 등급**: 필수 카메라·적도의 / 준필수 포커서·가이더("없이 진행" 가능) / 선택 허브·필터휠·회전장치·플랫패널(실패해도 경고만) / 제외 돔·안전 모니터·날씨 장치
- **장비 변경 모드**(사용자 설계): 모두 연결되면 4초 막대, 3.5초까지 "장비 변경" → 원들이 가운데 원 뒤로 흡수 → 8종 아이콘 원이 펼쳐짐 → 원을 누르면 옆에 설치된 드라이버 목록(N.I.N.A. list-devices) → 등록·변경·제거 → "변경 완료" → 바뀐 장비만 연결
  - 시뮬레이션에서는 N.I.N.A. 프로필을 건드리지 않고 AA 데이터 폴더 `rig-overrides.json`에만 저장
  - 변경 모드 가로 자리: 창 너비 0~10 기준, 오른쪽 6.7·7·8·8.5, 왼쪽은 좌우 대칭
- 연결 안 된 원: 가리키면 다시 연결 아이콘(준필수는 "없이 진행"), 누르면 가운데에 "○○ 연결되지 않음". 해결 방법 툴팁은 없앰
- 전원 허브가 실패하면 허브 원 바깥 고리가 깜빡임
- 배치: 넓이가 고르게 퍼지는 무작위 배치, **앱을 다시 켤 때까지 고정**. 원 사이 최소 간격 = 가장 작은 원의 반지름
- 자비스 원: 120% 크기, 글자 세로 가운데, 1단계 → 장비 연결로 끊김 없이 옮겨 오며 작아짐, 글자는 흐려졌다 밝아지며 바뀜(완료 문장은 바로)
- 누를 수 있는 것의 상태 네 가지(normal/hover/selected/disabled)를 이 화면에 먼저 정의 — 다른 화면에도 적용할지 결정 필요 (DESIGN.md 공통 규칙 후보)
