## 2. 기타 질문과 답
- **Opus 5.5 중간 설정이면 충분?** 화면·문구·문서는 중간으로 충분. 원인 모를 버그, 이상 복구·상태 관리 설계, 실제 장비를 움직이는 코드, 구조 변경은 높게
- **Artifacts 디자인으로 시안?** 코드로 만들기 전 시안 비교 용도로 의미 있음. 단 실제 앱은 `web/` 코드로 다시 만들고, 기준은 DESIGN.md 하나로. Design 캔버스 형식은 서비스 오류로 못 만들어서 일반 HTML 페이지로 시안을 만듦
- **집 PC에서 2단계부터 개발하려면?** 1단계 엔진 켜기는 시뮬레이션이 없고, 장비 연결도 NINA 프로필을 실제로 읽음 → NINA가 필요. 선택지: (A) NINA+가상 장비 설치, (B) 엔진 단계도 시뮬레이션, (C) 시안만. 이번에는 C로 진행
- **채팅 기기 간 동기화?** Code 탭 대화는 이 PC에만 저장됨. 대화 요약을 저장소에 남기는 방식으로 이어감 (이 파일)
- **스트링 데이터 테이블?** 지금은 불필요(한국어 하나, 문구가 계속 바뀜, 코드에서 문장이 안 보임). 다른 언어를 넣거나 사용자가 코드 없이 문구를 고치고 싶어질 때 전환. 앱 이름은 이미 product.json으로 분리됨

## 3. 흐름 결정
- **장비 연결 다음은 "계획"** (flow.mmd ② 그대로). 딥스카이 일반 순서로도 계획은 별 없이 할 수 있는 마지막 일
- 일반 딥스카이 순서(준비 단계용 참고): 냉각 시작 → 계획 → 대충 초점 → 극축 정렬 → GoTo·센터링 → 정밀 초점 → 구도 → 가이딩 → 시험 촬영 → 시퀀스
- **연결과 계획 사이에 "출발 전 점검" 추가** (사용자 제안). AA가 스스로 알 수 없는 것만 묻는다
- **앱 초기 화면을 없애고 출발 전 점검으로 대체.** 초기 화면 기능 이동: 날씨 → 상태 줄·계획 화면(예보는 온라인 API 자동), 장비 새로고침·재선택 → 이 단계에선 없음(상태 줄 장비 점, 촬영 중 끊김은 ⑥), 기록 보기 → 계획 화면
- **단계**: 연결 → 점검 → 계획 → 준비 → 촬영 → 마무리
- **카메라 냉각**: 냉각 카메라는 목표 온도를 정해 줘야 냉각됨. AA가 장비 연결 직후 뒤에서 시작, 상태 줄에 온도. 사용자 카메라(X-T5 미러리스)는 냉각이 없으니 냉각 표시를 숨김
- **날씨 예보 API 후보**: Open-Meteo(구름, 무료·키 없음), 7Timer! ASTRO(시잉·투명도), 기상청 단기예보(키 필요)

## 4. 출발 전 점검 화면 (확정)
- 제목 "촬영 시작 전에 장비를 한 번 둘러봐 주세요", 3×2 타일: 적도의 시작 위치 · 경통 캡 · 케이블 정리 / 경통 밸런스 · 삼각대 수평 · 이슬 방지 열선([임시] 제안 항목)
- 확인 개수 `n/6`은 오른쪽 위 타일 모서리 바로 위, **타일 바깥**
- 하단은 "건너뛰기" 버튼 하나(테두리만). 누르면 가라앉아 사라지고 남은 타일이 왼쪽 위부터 하나씩 확인됨으로 바뀜
- 6개가 되면 "다음" 없이 타일이 한꺼번에 투명해지며 자동 진행 (수동 체크도 동일)
- DESIGN.md 1장에 규칙 추가: **사용자가 직접 체크하는 화면은 다 채우면 자동 진행, AA가 확인한 결과를 보여 주는 화면은 "다음"을 눌러야 진행**

## 5. 계획 단계 (할 일 확정, 화면은 시안)
- 할 일: 오늘 밤 조건 보기 → 대상 → 구도 → 촬영 설정(노출·ISO·필터·끝나는 조건) → 끝난 뒤 → 계획 카드 → 준비
- 결정
  1. 후보 비교 GoTo는 **준비 단계로**. 계획에서는 화면 속 미리보기로만 (적도의 안 움직임)
  2. 끝나는 조건 기본값: **대상이 낮아지거나 새벽이 올 때까지**
  3. 노출·ISO는 AA가 **단순 표 기준으로 추천**, 기록이 쌓이면 발전
- **온라인 필수** (사용자 제안, Claude 동의): 시작·계획은 온라인 필수(휴대폰 핫스팟). 촬영이 시작된 뒤에는 끊겨도 촬영 계속. 인터넷 확인은 **1단계 엔진 켜기의 세 번째 항목**으로(0단계는 설치 여부만 보는 단계라서)
- 화면 구성(사용자 제안): 왼쪽 1/3 AA 대화(선택지 칩 포함), 오른쪽 위 1/4 오늘 밤 조건 그래프, 아래 3/4 계획 4칸(2×2) + 계획 카드 줄("이 계획으로 준비 시작")
  - 지금 묻는 칸 = 강조색 외곽선 → 사용자 OK
  - 오늘 밤 그래프: 정보는 다 필요하지만 해석이 어려움 → **나중에 재검토** (DESIGN.md에 [재검토] 표시)
  - 왼쪽 대화는 AI 대화로 설계(온라인 전제). 구현을 AI부터 할지 정해진 질문부터 할지는 코드 작업 때
